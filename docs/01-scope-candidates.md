# 纪录片收录范围：候选清单（待挑选）

> 目的：先拉一个**尽量大的候选池**，由你勾选后收敛成正式范围。
> 用法：直接在 `[ ]` 里打 `x`，或回复编号（如 “UK-1、US-1~4 保留，ASIA-5 不要”）。
> 说明：每个品牌后面的“HD 起点”是**大致估计**，用来定该品牌的收录起始年份，建库时再按实际片源核实。

---

## 0. 需要你先拍板的几个范围问题

- [ ] **Q1 起始年份**：统一从 2010 年起？还是“按品牌各自 HD 起点”？（建议：默认 2010，个别品牌例外，见下文）
- [ ] **Q2 经典回补**：2010 年前但已是高清的神作（如 *Planet Earth* 2006、*Life* 2009、*Wild China / 美丽中国* 2008）要不要作为“经典”例外收录？
- [ ] **Q3 自然/地理类**：你没提，但它是纪录片最大的一类（BBC NHU、Our Planet 等），要不要纳入？
- [ ] **Q4 时政/调查新闻**（FRONTLINE、Panorama、Four Corners、VICE）要不要？
- [ ] **Q5 纪实剧/历史重演**（*Roman Empire*、*Mars* 这类半剧情半纪录）要不要？
- [ ] **Q6 院线纪录长片**（*Inside Job*、*Apollo 11*、*AlphaGo*）要不要？——它们没有“品牌栏目”，需要按奖项/电影节来跟踪。
- [ ] **Q7 YouTube / B 站优质频道**（Kurzgesagt、Real Engineering、小Lin说…）要不要？——更新频率高、单集短，数据模型和“系列纪录片”不同。
- [ ] **Q8 语种**：只收中英？还是包括日、韩、德、法原产（字幕可后补）？
- [ ] **Q9 默认排除**：伪科学（*Ancient Aliens*、*Ancient Apocalypse*）、真人秀（*Gold Rush*）、真实犯罪、体育/音乐/明星传记——是否全部排除？

## 4. 对后续设计有影响的观察（备注，不需要勾）

- **合拍与重复**：同一部片常有多个品牌（如 BBC × Discovery、BBC × CCTV、NatGeo 与 Disney+ 同片），需要“作品”与“出品方/播出方”多对多，跟踪时去重。
- **长青栏目 vs 独立系列**：*Horizon*、*NOVA*、*American Experience* 这类一年几十集的栏目，和 *Planet Earth III* 这种独立系列，跟踪粒度不同（栏目按集、系列按季）。
- **中英文名对应**：同一部片常有多个中文译名（如 *Blue Planet II* =《蓝色星球2》），需要别名字段。
- **元数据来源候选**：TMDB、IMDb、豆瓣、各台官网节目单；YouTube 走频道 API。
